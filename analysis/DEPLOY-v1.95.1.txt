WHAT CHANGED
------------

1. ONE TAB NO LONGER UNLOCKS THEM ALL. sheetLocks and applyLocks lock each
   tab on its own. Before, one tab whose lock could not be worked out threw
   out of the whole list, Set up swallowed the error, no tab was locked, and
   the Set up message still said the protection was done. A tab with only
   its header row was one such tab. Now that tab is named and the rest are
   locked.

2. SET UP SAYS WHAT IT COULD NOT LOCK, in the same list as the skipped
   dropdowns.

3. LOCKED WHEN MADE. A tab made after Set up (Checks and Defects on the
   first walkaround, the Vehicle Log and History on the first sync, the
   archive tabs) is locked as it is made (relockIfNeeded).

4. LOCKED AGAIN OVERNIGHT. The 3am pass locks any tab with no lock. Unlock
   the sheet lasts until then.

5. IS EVERYTHING WORKING? names any tab not locked (locksHealth).
