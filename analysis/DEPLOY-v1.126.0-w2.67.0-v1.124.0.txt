Asim, 17 Oct: the Apps Script web app's address (the deployment ending
…1XxMSA) was in config.js and in the Apps Script workflow, both public.

1. config.js no longer has it. The driver app's fallback to the sheet now
   goes to the live server's /sheet, which passes the call on to the
   address the sheet sends on each sync (Script Property WEB_APP_URL).
   It passes on only what a phone could always send, and never with the
   sheet's own password. It works only with SHEET_TOKEN set on both sides.
2. The Apps Script workflow reads the deployment from the repository secret
   DEPLOYMENT_ID, which GitHub also blanks out of the run logs. Without it
   the run goes red and Code.gs does not go live.
3. The sheet asks for its own password (SHEET_TOKEN) on report and pdf as
   well, the two the coordinator app asks through the live server.
4. The live server's status answer gives the sheet its address only when
   SHEET_TOKEN is set.

The old address is still in the repository's history and in earlier
Actions logs, so only a fresh deployment makes the address private.
