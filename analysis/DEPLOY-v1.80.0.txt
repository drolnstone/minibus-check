WHAT CHANGED
------------

1. THE COORDINATOR IS A ROW ON THE DRIVERS TAB.
   Whoever has Role Coordinator is who every page tells people to ring, on
   the number in that row's Phone column. The sheet sends it to the live
   server on every push, and an edit to the Drivers tab pushes within
   seconds. The live server keeps it and puts it on every answer it gives.
   The driver app and the passenger page take it from whichever answer
   they get first and keep it on the phone for when there is no signal.
   Changing coordinator is now two cells on that tab.

2. config.js NAMES NOBODY.
   Its coordinator line is gone, and its driver register and both rota
   orders are empty. They already came from the Drivers tab with the rota,
   and still do. config.js keeps only addresses and switches.

3. THE CODE STARTS BLANK FOR A NEW CHURCH.
   The list Code.gs wrote into a blank Drivers tab on first setup is empty,
   and so is the spare North rota order in the driver app. On a brand new
   sheet the Role and Phone headings carry notes saying what Coordinator
   and Phone are for.

4. v1.85.1: THE COORDINATOR'S NUMBER IS TIDIED BEFORE IT IS SENT.
   Sheets stores a number typed as +44 7700 900123 as the plain number
   447700900123, and v1.85.0 sent it like that, so the call button dialled
   447700900123, which goes nowhere from a UK phone. It is now sent as
   07700900123, the same tidying the bookings already use. Only Code.gs
   changes: paste it and deploy a new version, then Send everything to the
   live server now.
