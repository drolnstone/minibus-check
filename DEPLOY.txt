WHAT CHANGED
------------

1. BUS LINK FOR THIS SUNDAY. The passenger page's address, with a button
   that opens WhatsApp ready to send it to a person or the group, and one
   to copy it. Built in the app itself; it needs neither server.

2. IS THE LIVE SERVER WORKING? and WHO IS TAPPING. Built by the sheet, the
   same code as the menu items, handed back through the live server after
   it has checked the PIN. The menu items are unchanged.

3. SEND DUTY REMINDERS NOW. The same as the menu item: sends only the
   reminders due today, and never the same one twice. The app asks
   "Send the duty reminders due today?" first, and has no Ask again on the
   answer, so it cannot be sent by a stray tap.

4. A TEST THAT FAILED AFTER NINE AT NIGHT. One coordinator-alert test ran
   on the real clock and, in the quiet hours, rightly saw a non-urgent
   alert held for the morning. It now runs at two in the afternoon. The
   app was never wrong.
